# Mira AI Access Backend

Welcome to the **Mira AI Backend** documentation. This service powers the Mira AI platform, handling patient management, AI voice agents, appointment scheduling, and communication workflows.

## Features

*   **FastAPI & Python 3.12+**: High-performance, async-first API.
*   **AI Integration**: Powered by Google Gemini 2.0 Flash for intelligent analysis.
*   **Voice Agents**: Real-time voice interaction via LiveKit.
*   **PostgreSQL & SQLAlchemy**: Robust data management with async migrations.
*   **Task Queue**: Celery & Redis for background processing (emails, reports).
