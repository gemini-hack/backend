# Mira AI 🩺

Mira AI is an advanced healthcare provider assistant designed to empower medical teams in managing chronic conditions through a multi-agent AI architecture. By leveraging Large Language Models (LLMs) and clinical logic, Mira AI helps healthcare workers monitor patient health, manage treatment adherence, and coordinate interventions efficiently.

---

## 🚀 Key Features

### Multi-Tenancy & Security
- **Organization Management**: Built for hospitals and clinics as distinct tenants.
- **Role-Based Access Control (RBAC)**: Secure access for Doctors, Nurses, and Coordinators.
- **Audit Logging**: Comprehensive tracking of all authentication and clinical events.

###  Multi-Agent AI System (T-MAC Architecture)
- **Head Doctor (Supervisor)**: Orchestrates morning rounds, coordinates specialist agents, and synthesizes final clinical decisions using Gemini Pro.
- **Disease-Specific Specialists**: Dedicated workers for HIV, Hypertension, and more, analyzing condition-specific data (e.g., viral load suppression).
- **Engagement Specialist**: Monitors patient activity and flags disengaged users.
- **Clinic Critic**: Performs quality control by reviewing AI-generated actions before they are presented to staff.

### Clinical Management
- **Modular Condition Profiles**: Extensible architecture allowing for disease-specific clinical data (currently supporting HIV/ART management).
- **Automated Defaulter Tracing**: Systematically flags patients who miss refills or clinical appointments.
- **Priority Alerts**: Urgent and critical alerts generated by agents for immediate medical attention.

### Communication & Tasks
- **Celery Background Workers**: Handles heavy lifting like email delivery and periodic analysis rounds.
- **Email Verification**: Ensures security through mandatory email verification on registration.

## Tech Stack

- **Framework**: [FastAPI](https://fastapi.tiangolo.com/) (Python 3.12+)
- **Database**: [PostgreSQL](https://www.postgresql.org/) with [SQLAlchemy](https://www.sqlalchemy.org/) & [Alembic](https://alembic.sqlalchemy.org/)
- **AI/LLM**: [Google Gemini GenAI](https://ai.google.dev/)
- **Cache & Tasks**: [Redis](https://redis.io/) & [Celery](https://docs.celeryq.dev/)
- **Dependency Management**: [uv](https://github.com/astral-sh/uv)
- **Infrastructure**: [Docker](https://www.docker.com/) & [Docker Compose](https://docs.docker.com/compose/)

## Getting Started

### Prerequisites
- Docker & Docker Compose
- Google Gemini API Key

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/gemini-hack/backend.git
   cd backend
   ```

2. **Configure Environment Variables**:
   Copy the sample environment file and fill in your secrets (especially `GOOGLE_API_KEY`, `DATABASE_URL`, and `REDIS_URL`).
   ```bash
   cp .env.sample .env
   ```

3. **Start the Stack**:
   Use Docker Compose to build and start the application, database, redis, and workers.
   ```bash
   docker compose up --build
   ```

4. **Access the API**:
   - **API Base**: `http://localhost:8000/api/v1`
   - **Interactive Documentation**: `http://localhost:8000/docs`

```text
├── tests/              # Automated tests

├── compose.yml         # Container orchestration
└── main.py             # App entrypoint
```

## 📜 Contributing

Mira AI is built for extensibility. To add a new disease specialization:
1. Create a profile model in `app/models/conditions.py`.
2. Add a corresponding specialist agent in `app/agents/workers/`.
3. Register the worker in `app/agents/factory.py`.
